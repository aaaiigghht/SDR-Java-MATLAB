### Реалізація програмного засобу та умови його використання
Розроблення програмного додатку здійснювалося поетапно із використанням персонального комп’ютера під керуванням операційної системи Microsoft Windows.
Як середовище розробки було використано IntelliJ IDEA, яке забезпечує зручні засоби для створення, редагування та налагодження програмного коду мовою Java.  
Дане середовище характеризується широкими можливостями інтеграції з системами контролю версій, а також наявністю вбудованих інструментів для аналізу та відлагодження програм.
Програмна реалізація інтерфейсу користувача та основної логіки функціонування додатку виконана мовою Java. 
Для реалізації процесів математичного моделювання сигналів і каналів зв’язку використано MATLAB, що надає ефективні засоби для виконання чисельних обчислень, аналізу сигналів та візуалізації результатів.
Інтеграція між Java-додатком і середовищем MATLAB здійснена із застосуванням MATLAB Engine API for Java, що дозволяє безпосередньо викликати MATLAB-скрипти з програмного коду.
Для організації процесу розробки було використано систему контролю версій Git. 
Вихідний код розміщено у віддаленому репозиторії на платформі GitHub, що забезпечує централізоване зберігання проєкту, контроль змін та можливість доступу до нього.
Після завершення етапу розроблення програмний продукт було зібрано у виконуваний файл формату .jar, що забезпечує можливість його запуску без необхідності використання середовища розробки.

### Програмні засоби та технології розробки   
* Microsoft Windows — операційна система, яка забезпечує виконання програм, взаємодію з користувачем та роботу з файлами
* IntelliJ IDEA — інтегроване середовище розробки, яке використовується для створення та налагодження Java-додатку
* Java — мова програмування, що використовується для реалізації логіки роботи додатку та створення графічного інтерфейсу
* MATLAB — середовище для виконання математичних обчислень, яке застосовується для моделювання сигналів та каналів зв’язку
* MATLAB Engine API for Java — забезпечує взаємодію між Java-додатком та MATLAB
* Git — система контролю версій, яка дозволяє відстежувати зміни у коді
* GitHub — платформа для зберігання та управління репозиторієм проєкту

### Вимоги до середовища виконання 
* наявність операційної системи Microsoft Windows версії 10 або новішої
* встановлений Java Development Kit версії 21 або вище
* встановлене середовище MATLAB
* налаштований MATLAB Engine API for Java
* наявність усіх файлів проєкту, зокрема Java-коду та MATLAB-скриптів

### Структура програмного проєкту 
Проєкт має наступну структуру:
1. Папка .idea — службова папка середовища розробки IntelliJ IDEA, яка містить налаштування проєкту, конфігураційні файли та параметри середовища. Дана папка не впливає на роботу програмного додатку під час його виконання.
2. Папка src — основна папка, що містить вихідний код Java-додатку. У даній папці реалізовано:
   - графічний інтерфейс користувача
   - обробку введених параметрів
   - взаємодію з MATLAB
   - запуск процесів моделювання
   - відображення результатів
3. Папка matlab — містить MATLAB-скрипти, які реалізують математичну частину проєкту, зокрема:
   -  генерацію сигналів
   -  додавання шумів і перешкод
   -  реалізацію різних видів модуляції (BPSK, QPSK, QAM). 
   -  аналіз сигналів
   -  побудову графіків результатів моделювання
4. Файл .gitignore — використовується для визначення файлів і папок, які не включаються до системи контролю версій Git. Це дозволяє уникнути збереження службових та тимчасових файлів.
5. Файл README.md — містить опис програмного засобу, вимоги до програмного забезпечення, інструкцію встановлення та запуску.
6. Файл untitled7.iml — конфігураційний файл середовища розробки, який використовується для зберігання параметрів проєкту в IntelliJ IDEA.
   
### Запуск програмного додатку
Для запуску програмного засобу необхідно:
1.Відкрити папку, що містить .jar файл.
2. Запустити командний рядок у даній папці.
3. Виконати команду:
> java -jar untitled7.jar

Після виконання команди відкривається графічний інтерфейс додатку, який дозволяє здійснювати моделювання сигналів та аналіз отриманих результатів.

#### Особливості функціонування програмного засобу
* інтеграція Java та MATLAB дозволяє поєднати зручний інтерфейс з потужними математичними обчисленнями
* запуск MATLAB відбувається автоматично під час виконання програми
* користувачу не потрібно вручну відкривати MATLAB
* результати моделювання формуються в процесі роботи та можуть бути використані для подальшого аналізу
* підтримується моделювання різних типів модуляції та впливу шумів у каналі зв’язку
